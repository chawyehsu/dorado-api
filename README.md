# dorado-api

Some APIs that [dorado](https://github.com/chawyehsu/dorado) bucket uses to
maintain manifests.

Powered by [Deno](https://deno.com) and hosted on
[Deno Deploy](https://deno.com/deploy).

## Development

Run with `deno serve`:

```bash
deno task start
```

or with watch mode:

```bash
deno task dev
```
